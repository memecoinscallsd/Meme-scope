# Meme-scope

Real-time Pump.fun token monitoring bot with smart filters.

## Features

- 🚀 Real-time monitoring of new Pump.fun token launches
- 📊 On-chain metrics analysis
- 🎯 Smart filtering based on winning patterns
- 📱 Telegram alerts
- ⚡ Continuous polling every 30 seconds

## Filters

- Top 10: 15-50%
- Holders: 150-5000
- Dev: ≤10%
- Liquidity: $0-$100k
- Bonding: 15-85%
- Volume: $5k+
- Marketcap: $1k-$500k

## Deployment

Deploy on Railway from this GitHub repo. The bot will run continuously and send Telegram alerts for matching tokens.
